## 2. 验收标准

| # | 标准 | 判据 | 数据来源 |
| --- | --- | --- | --- |

## 3. 退出条件（进入 M3 的门槛）

- ✅ Eval 集指标达到 mission.md KPI：行动项三要素完整率 ≥ 85%、人工返工率 ≤ 20%、说话人正确率 ≥ 80%。
- ✅ FR-08~11 全部实现（含 FR-03 说话人、FR-05 结构化抽取细化）并通过测试。
- ✅ 支持人工编辑、批注并持久化。
- ✅ 单元测试覆盖率 ≥ 70%。

## 5. 判定规则

- 行动项三要素完整率 ≥ 85% 且返工率 ≤ 20% 且说话人正确率 ≥ 80%、FR-08~11 全部实现、覆盖率 ≥ 70% → M2 通过。
- 任一指标不达标 → 定位到对应任务组补齐（完整率 → TG-1、说话人 → TG-2、模板/角色 → TG-4/TG-3），回归评测直至达标。
- 若云 ASR 话者分离不可用 → 以 pyannote/whisperX 兜底跑通，并在评测报告中如实记录「话者分离方案由云 ASR 降级为本地 pyannote」。
- 若云 API 密钥不可用导致抽取无法端到端验证 → 用 extractive 规则兜底跑通链路以验证 Schema / 模板 / 编辑 / 检索闭环，明确记录阻塞原因与缺口指标，密钥到位后回填评测数据。
