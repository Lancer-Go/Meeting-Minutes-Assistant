## 2. 验收标准

| # | 标准 | 判据 | 数据来源 |
| --- | --- | --- | --- |
| V1 | 转写准确率 | 产出中文 CER 实测值（目标 ≥ 92%） | TG-3 |
| V2 | 纪要质量 | 对 ≥ 10min 音频输出**可读、结构完整**的 Markdown 纪要 | TG-4 / TG-5 |
| V3 | 耗时 | 单场耗时 ≤ 会议时长 1/3 | TG-5 |
| V4 | 成本 | 单场成本 ≤ ¥1/场 | TG-5 |
| V5 | 选型结论 | 明确锁定 ASR 厂商与 LLM 主方案 | TG-6 |

## 3. 退出条件（进入 M1 的门槛）

- ✅ 纪要质量达**可读**水平。
- ✅ 耗时 / 成本落在 mission.md §6 KPI 量级内（耗时 ≤ 时长 1/3、成本 ≤ ¥1/场）。
- ✅ 产出《选型决策记录》，结论明确，可直接作为 M1 的 ASR/LLM 配置输入。

## 5. 判定规则

- 三组数据（CER / 耗时 / 成本）**全部产出**且落在 KPI 量级内 → M0 通过。
- 任一指标不达标 → 回到对应任务组（换厂商 / 换模型 / 调提示词）重测，直至达标或明确记录阻塞原因。
